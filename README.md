# UltraDM

مدير تحميلات لسطح المكتب (ويندوز) مبني بـ **Tauri 2 + Rust** للخلفية و**React + TypeScript + TailwindCSS v4** للواجهة، بواجهة عربية من اليمين إلى اليسار تدعم الوضعين الليلي والنهاري.

## التشغيل

```bash
npm install
npm run tauri dev     # وضع التطوير
npm run tauri build   # حزمة تثبيت ويندوز (NSIS + MSI) في src-tauri/target/release/bundle
```

متطلبات بناء ويندوز: Rust (MSVC) و WebView2 (مضمّن في المثبّت عبر embedBootstrapper).

## البنية

- `src/` — واجهة React: شريط جانبي للتصنيفات (الكل، فيديو، صوت، مضغوط، برامج، مستندات، تورنت)، شريط علوي (إضافة رابط/تورنت، إيقاف، استئناف، حذف، جدولة، تبديل الوضع)، جدول التحميلات (الاسم، النوع، الحجم، التقدم، أقصى سرعة، السرعة الحالية، المتبقي، الخيوط حتى 32)، رسم بياني حي للسرعة، وشريط سفلي للإجراء بعد انتهاء التحميلات (إغلاق الجهاز، سكون، إغلاق البرنامج).
- `src-tauri/` — خلفية Rust: أوامر IPC محدودة (`shutdown_device`، `sleep_device`، `exit_app`، `app_info`)، أيقونة صينية، وقائمة إنهاء. إجراءات الطاقة تعمل على ويندوز فقط.
- `src-tauri/tauri.conf.json` — إعدادات البناء: ضغط LZMA لمثبّت NSIS، أهداف nsis + msi.

## ضغاط الحجم والرام (release profile في src-tauri/Cargo.toml)

`opt-level = "z"`، `lto = "fat"`، `codegen-units = 1`، `panic = "abort"`، `strip = true` — مع عرض WebView2 النظامي لا يستهلك التطبيق نفسه ذاكرة WebView؛ الاستهلاك الفعلي أقل من 30MB في حالة الخمول لأن الواجهة خفيفة (~80KB gzip) والمحتوى ثابت.

## حالة محرك التحميل

الواجهة مكتملة وتعمل؛ محرك التحميل الفعلي (HTTP متعدد الخيوط وتورنت) لم يُربك بعد — القائمة الحالية في وضع المعاينة داخل المتصفح تحاكي التقدم، وفي نسخة سطح المكتب تبدأ فارغة والأزرار تعمل عبر IPC. ربط المحرك هو الخطوة التالية.
